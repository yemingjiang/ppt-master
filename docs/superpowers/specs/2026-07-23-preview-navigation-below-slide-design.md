# Preview Navigation Below Slide Design

> **Superseded on 2026-07-23.** The final user-approved behavior places Previous/Next on the right side of the top current-slide takeaway card. Do not use the below-slide layout described in this historical design.

## Context

The review preview generated by `build_preview_html.py` currently places a wide toolbar above the slide. The toolbar contains the current slide title, review-scope guidance, and Previous/Next buttons. This consumes vertical space before the content being reviewed and separates the navigation controls from the slide they operate on.

## Approved Behavior

- Remove the top toolbar from `preview/index.html`.
- Do not render the duplicated current-slide title or the review-scope sentence in the main preview column.
- Render a compact navigation row immediately after the slide viewer.
- Keep the Previous and Next buttons in their existing order and align the pair to the right.
- Preserve the existing button IDs and JavaScript behavior so mouse and keyboard navigation remain unchanged.
- On narrow screens, keep the navigation row below the viewer and allow the controls to use the available width without overlapping the slide.

The left outline, takeaway card, slide iframe, inspector, comments, hash navigation, and keyboard behavior remain unchanged.

## Structure

The main review column uses this order:

1. Current-slide takeaway card
2. Slide viewer
3. Bottom navigation row

The bottom row is a presentation-review control, not part of the slide iframe and not an overlay. It must not cover slide content.

## Implementation

- Update `skills/ppt-master/scripts/build_preview_html.py`:
  - remove `.toolbar`, `.toolbar-title`, and `.toolbar-note` markup and styling;
  - remove the `slideToolbarTitle` lookup and update;
  - add a dedicated bottom-navigation container after `.viewer-shell`;
  - update `.main` grid rows and responsive styles for the new order.
- Update `skills/ppt-master/SKILL.md` so Step 6 and the Notes section state that preview navigation belongs immediately below the current slide and that the removed toolbar copy must not be reintroduced.
- Update `skills/ppt-master/scripts/test_build_preview_html.py` with structural assertions that:
  - the viewer appears before the navigation container;
  - Previous appears before Next;
  - the obsolete toolbar title and review-scope copy are absent;
  - the existing navigation IDs and handlers remain present.

## Validation

- Run the focused preview-builder test first and observe the new structural test fail before implementation.
- Run the focused test again after implementation.
- Run the complete script test suite and skill validator.
- Build a representative preview and inspect its HTML structure.
- Open the representative preview in a browser and verify the controls sit below the current slide on desktop and narrow layouts.

## Non-goals

- Do not change the final single-file HTML presentation controls.
- Do not change slide content, SVG generation, notes, comments, or the left outline.
- Do not add sticky or overlay navigation.
